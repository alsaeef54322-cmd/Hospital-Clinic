# 🏥 Clinic Management System

نظام متكامل لإدارة العيادات الطبية، مصمم لتسهيل إدارة بيانات المرضى والمواعيد والخدمات الطبية بطريقة بسيطة ومنظمة.

## ✨ فكرة المشروع

يساعد النظام الطبيب أو موظفي العيادة على إدارة العمليات اليومية من مكان واحد، بدلًا من الاعتماد على الملفات الورقية أو الطرق التقليدية.

## 🚀 أهم المميزات

* 👨‍⚕️ إدارة بيانات الأطباء.
* 👤 إضافة وتعديل وحذف بيانات المرضى.
* 📅 حجز وإدارة مواعيد الكشف.
* 🔍 البحث عن المرضى والمواعيد بسهولة.
* 📋 تسجيل بيانات الزيارات والكشف.
* 💊 تسجيل التشخيص والأدوية.
* 💰 إدارة أسعار الخدمات والمدفوعات.
* 📊 عرض إحصائيات عن العيادة.
* 🌙 دعم **Dark Mode / Light Mode**.
* 💾 حفظ البيانات محليًا باستخدام **LocalStorage**.
* 📱 تصميم Responsive يعمل على الكمبيوتر والموبايل.

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* LocalStorage
* Responsive Design

## 🎯 الهدف من المشروع

الهدف من المشروع هو إنشاء نظام عملي وسهل الاستخدام يساعد العيادات على تنظيم بيانات المرضى والمواعيد والخدمات، بالإضافة إلى تطبيق مفاهيم **JavaScript وDOM وLocalStorage وCRUD** في مشروع حقيقي.
